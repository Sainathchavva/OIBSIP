# Tribute Page — Srinivasa Ramanujan

## About This Project
I chose Srinivasa Ramanujan for this tribute page because his story stood
out to me while researching subjects for this assignment — a
self-taught mathematician from South India who produced original
mathematical results with almost no formal training, and was eventually
recognized by Cambridge University. I wanted the page to reflect that
mix of humble background and extraordinary achievement.

## Tech Stack Used
- HTML5
- CSS3
- JavaScript (optional — used only for a small scroll animation)

## Files in This Submission
- `index.html` — page structure and content
- `style.css` — all styling, colours, fonts, and responsive rules
- `script.js` — optional JS for a fade-in effect on the timeline cards
- `README.md` — this file

## How I Approached the Feature Checklist
- **Title + tagline** — added at the top in the hero section
- **Image** — sourced from Wikimedia Commons (public domain portrait of
  Ramanujan), linked using Wikimedia's stable `Special:FilePath` link so
  it doesn't break if the file is renamed
- **Biography** — 4 paragraphs, written in my own words after reading
  about him on Wikipedia; not copy-pasted from any source
- **Timeline** — built as styled cards in a CSS grid, covering 1887 to
  1920
- **Quote block** — a short quote attributed to Ramanujan, styled with a
  large decorative quotation mark
- **Two background colours** — alternates between a warm off-white
  (`#faf6ef`) and a dark navy (`#1b2a4a`) across sections
- **Two font styles** — serif (Georgia) for headings/quote, sans-serif
  (Segoe UI) for body text
- **Responsive layout** — timeline grid drops from 3 columns → 2 → 1 as
  the screen gets smaller (media queries at 768px and 480px)

## How to Run It
1. Keep all three files (`index.html`, `style.css`, `script.js`) in the
   same folder.
2. Double-click `index.html` or open it in any browser.
3. No installation or server needed.

## Sources I Used
